You can write forward, too.

A few gentle boundaries.

Do I need to finish all the prompts?

No. Enter one thought and build the draft. Delete any framing that does not sound like you. A short letter is still a letter.

Will this save or send my letter?

No. There is no account, submission or autosave. Text exists only in the page until you copy it. Refreshing or leaving can erase it. The copy button writes to your device clipboard only.

What if I don't want to revisit a difficult memory?

Choose an ordinary, comfortable moment instead, or stop. This is an optional writing exercise, not a therapy tool or a mental-health service.

Can I change the generated wording?

Yes. The draft is a normal text box. Changing the prompt notes does not overwrite it automatically. Building again replaces the draft with a new template from your current notes.
