Proposed discussion agenda

Family visits / Explore possibilities

  1. Which visit are we discussing first?
  2. Ask each person: what matters to you about this, and what would you like the other person to understand?
  3. Which dates are genuinely available, and which invitations are still only possibilities?
  4. Could we shorten a visit, split the days, alternate this year, or decline one invitation?
  5. Keep the options as possibilities. Ask what each person wants to think about before revisiting them.

A proposal, not an agreement. Either person can pause or decline.

02

Separate the question from the whole history.

For this planning exercise, make the first question concrete enough to answer. You can return to a larger concern separately; it doesn't have to be squeezed into a travel booking decision.

Broad topic
"The holidays always turn into too much."

One planning question
"Which invitation do we want to discuss first, before we reply to anyone?"

Illustrative wording, not a real couple's testimonial. Use it only if it matches what you mean.

03

A possible plan is still a possibility.

A draft in one person's notes isn't a shared decision. Before treating an option as settled, check whether each person freely agrees. "Not yet" is an available answer.

If one person needs more time, the next step can be more time. There is no score, deadline or requirement to reach an agreement on this page.

This tool is for voluntary planning conversations. It isn't appropriate for pressuring someone to compromise a boundary, or for situations involving fear, coercion or abuse. An app does not replace appropriate support.
